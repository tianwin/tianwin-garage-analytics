# Project Brief

## Stakeholder

Owner / operations manager of a mobile automotive service business.

## Decision needs

- Revenue monitoring
- Service prioritization
- Customer retention
- Revenue concentration
- Data-quality improvement

## Success criteria

The analytics system should allow a manager to determine within a few minutes the current revenue and order-volume trends, average ticket, top services, repeat-customer importance, customer concentration, data limitations, and priority operational actions.

## Deliverable

A read-only, public-safe analytics case study with reproducible privacy transformation, SQL marts, centralized KPI definitions, interactive analysis, transparent recommendations, documentation, and automated tests.
